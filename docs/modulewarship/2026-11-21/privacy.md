# 隐私政策

**版本：2026-11-21 ｜ 更新日期：2026年11月21日 ｜ 生效日期：2026年11月21日**

## 引言

本游戏《方块战舰》（英文名 ModuleWarShip，以下简称"本游戏"）由 **LLL**（个人开发者，注册地址：浙江省台州市黄岩区，以下简称"我们"）运营。

我们深知个人信息对您的重要性，并会尽力保护您的个人信息安全。本政策旨在向您说明：我们收集哪些信息、为什么收集、如何保存与保护、与谁共享，以及您享有哪些权利。请您在使用本游戏前仔细阅读本政策，特别是加粗或标注"重要"的内容。

**本政策仅适用于本游戏。** 您通过 TapTap、Steam 等第三方平台使用服务时，还应遵守该平台自身的隐私政策。

## 本政策要点速览

- 本游戏的核心玩法为**单机离线**，存档、设置与日志均保存在您的设备本地，我们不上传。
- 我们**不收集**您的手机号、邮箱、通讯录、短信、相册、精确位置、剪贴板、IMEI、MAC 地址、应用安装列表。
- 为满足法律法规对游戏实名认证与未成年人保护的要求，Android 版在您登录 TapTap 账号后会进行实名认证与防沉迷校验；相关实名信息由 TapTap 直接收集，我们仅获取校验结果。
- 除 TapTap 登录与实名服务外，本游戏**未接入**广告、统计、推送、支付类第三方 SDK。
- 您可以随时撤回同意、删除本地数据并停止使用本游戏；具体路径见"四、您的权利"。

## 一、我们如何收集和使用您的个人信息

### 1.1 TapTap 账号登录与实名认证（Android 版）

- **收集内容**：TapTap 用户标识（unionId）、昵称、头像；设备型号、操作系统版本、网络状态；实名认证与防沉迷校验结果（是否通过、年龄段、可游戏时长等）。
- **目的**：完成账号登录；履行《中华人民共和国未成年人保护法》《关于进一步严格管理切实防止未成年人沉迷网络游戏的通知》等规定的实名认证与防沉迷义务；保障服务与账号安全。
- **方式与时机**：仅在您主动点击"登录"并同意本政策后，通过 TapSDK 向 TapTap 服务器发起。
- **关于实名信息**：姓名、身份证件号码等实名信息由 **易玩（上海）网络科技有限公司（TapTap）** 直接收集与处理，我们不会获取、存储或留存。
- **拒绝的后果**：您可以选择不登录。未完成实名认证时，依据法律法规要求，游戏将无法提供需要实名认证的在线功能（以 TapTap 合规校验结果为准）。

**重要**：若您使用的版本不包含 TapTap 登录功能（例如完全离线的版本或部分平台的版本），则不会发生本节所述的信息收集。

### 1.2 本地存档与设置

- **内容**：游戏进度、关卡与解锁状态、音量与画面等设置项。
- **存储位置**：仅保存在您设备的应用私有目录（Application.persistentDataPath）与系统首选项中。
- **是否上传**：不上传，我们无法访问。

### 1.3 您主动导入的文件（模组、存档等）

- 本游戏支持通过 Android 系统文件选择器（SAF）或 Windows 文件对话框导入模组与存档文件。
- 我们仅读取您主动选择的文件，文件内容保存在您的设备本地，不会上传；我们不会扫描您设备上的其他文件。

### 1.4 设备与运行日志

- **内容**：设备型号、操作系统版本、Unity 与游戏版本、运行平台、错误与警告日志及其堆栈。
- **目的**：仅用于在您的设备上排查运行故障。
- **存储与期限**：仅保存在本机日志目录，按文件数量与单个文件大小自动轮转、自动清空，不会自动上传。若您主动将日志发送给我们以寻求技术支持，视为您授权我们在处理该问题的必要范围内使用。

### 1.5 传感器数据

- 重力、加速度、陀螺仪等传感器数据用于屏幕方向适配与画面特效。
- 该数据在本机实时处理，**不存储、不上传**；您可在系统设置中关闭相关权限，关闭后仅影响对应表现效果。

### 1.6 访问本政策页面时的网络信息

本政策及相关法律文档托管于 GitHub Pages。您访问这些页面时，GitHub 会按其自身的隐私政策记录 IP 地址、浏览器标识、访问时间等日志，我们无法获取这些日志。

### 1.7 我们不会收集的信息

**我们不会收集**：手机号码、电子邮箱、通讯录、短信与通话记录、相册（您主动选择的文件除外）、精确地理位置、剪贴板内容、IMEI、MAC 地址、应用安装列表、广告标识符（OAID/IDFA/Android ID）、支付与银行卡信息、生物识别信息（人脸、指纹，您设备本地的系统解锁除外）。

### 1.8 征得同意的例外

根据《个人信息保护法》第十三条，在下列情形中我们处理您的个人信息无需取得您的同意：为履行法定职责或义务所必需；为应对突发公共卫生事件，或紧急情况下为保护自然人的生命健康和财产安全所必需；在合理范围内处理您自行公开或其他已经合法公开的个人信息；法律、行政法规规定的其他情形。

## 二、我们如何委托处理、共享、转让和公开披露

### 2.1 第三方 SDK 清单

本游戏接入的第三方 SDK 如下。除此之外，**未接入**任何广告、统计、推送、支付类 SDK。

- **SDK 名称**：TapSDK（TapTap 登录与合规）
- **提供方**：易玩（上海）网络科技有限公司
- **使用目的**：TapTap 账号登录；实名认证与防沉迷校验
- **收集的信息**：TapTap 账号标识、昵称、头像、设备型号与系统版本、网络状态、实名认证与防沉迷校验结果
- **隐私政策**：[TapTap 隐私政策](https://www.taptap.cn/privacy-policy)

### 2.2 共享、转让与公开披露

- 我们**不会出售**您的个人信息，也不会为第三方营销目的共享您的个人信息。
- 仅在以下情形共享：取得您的单独同意；依据法律法规或有权机关的要求；为保护您或他人的生命、财产安全所必需。
- 因合并、分立、解散、被宣告破产等原因需要转移个人信息的，我们会告知您接收方的名称与联系方式，并要求接收方继续履行本政策；接收方变更原有处理目的、方式的，将重新取得您的同意。
- 我们不会公开披露您的个人信息，法律另有规定或取得您单独同意的除外。

### 2.3 平台服务

- **Windows（Steam）版**：账号、好友、云存档等功能由 Steam 客户端与 Valve Corporation 提供，适用 Steam 的隐私政策；本游戏不收集您的 Steam 账号信息。
- **政策页面托管**：GitHub（GitHub Pages）。

## 三、我们如何存储和保护您的个人信息

### 3.1 存储地点

TapTap 相关信息的存储地点以 TapTap 的隐私政策为准。本游戏没有自建服务器，本地数据全部存储在您的设备上，**不涉及个人信息出境**。

### 3.2 存储期限

- 本地存档、设置与日志：保存至您删除对应数据、清除应用数据或卸载本游戏。
- TapTap 侧信息：按照 TapTap 的留存规则与法律法规要求处理。

### 3.3 保护措施

- 遵循最小必要原则，仅在实现功能所必需的范围内申请权限与处理信息。
- 本地数据存放于应用私有目录，其他应用无法直接读取。
- 与 TapTap 服务之间的网络传输使用 HTTPS 加密。
- 我们不建立服务器端个人信息数据库，从源头降低泄露风险。

### 3.4 安全事件处置

如不幸发生个人信息泄露、篡改、丢失等安全事件，我们将按照法律法规要求及时告知您，并向主管部门报告。

## 四、您的权利

您对您的个人信息享有以下权利，我们将在 **15 个工作日**内答复您的请求：

- **查阅、复制**：您可在游戏内查看存档与设置；如需了解我们持有的您的信息，可通过下方联系方式联系我们。
- **更正、补充**：发现信息不准确时，可联系我们更正；TapTap 账号信息可在 TapTap 客户端内修改。
- **删除**：您可删除游戏存档与日志；卸载本游戏或清除应用数据将删除全部本地数据。
- **撤回同意**：您可随时撤回对本政策的同意。撤回方式：在系统设置中清除本应用数据或卸载本游戏；撤回后我们将不再处理相应信息，但不影响撤回前基于同意已进行的处理。
- **注销账号**：本游戏没有自建账号体系，TapTap 账号的注销请在 TapTap 客户端内操作。
- **投诉举报**：您可通过下方联系方式投诉，也可向网信、公安、市场监管等部门举报，或通过 12321 网络不良与垃圾信息举报受理中心反映。

## 五、未成年人保护

- 若您为**未满 14 周岁**的未成年人，请在监护人的陪同下阅读本政策，并在取得监护人同意后使用本游戏。
- 我们根据国家有关规定对未成年人游戏时长进行限制；未成年人冒用成年人身份或使用他人账号的，我们有权终止服务。
- 监护人如发现我们在未获同意的情况下收集了未成年人的个人信息，可联系我们删除。
